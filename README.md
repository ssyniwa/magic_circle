# magic_circle
魔法陣構築 RPG App

概要
ランダムにドロップする魔法陣のパーツと武器を組み合わせ、キャラクターに装備させて全10ステージのクリアを目指す、新感覚のタクティカルRPGアプリです。Streamlitを用いて構築されており、ブラウザ上で手軽に遊ぶことができます。

主な特徴

ランダム武器クラフト（ガチャ要素）: ステージごとにドロップする属性ペア（炎・水・風・土・光・闇）や武器種（剣・杖・弓・槍）を組み合わせて、自分だけの武器を生成・強化します。

戦略的な装備フェーズ: 3人のキャラクター（戦士アレン、魔導士リリア、騎士レオン）の得意武器を見極めながら、重複のないように最適な武器を割り当てます。

3×3グリッドバトル: 敵が配置された3×3のマスに対し、武器ごとの攻撃範囲（前衛単体、縦一列、ランダム複数など）を考慮しながらターンを進めて戦います。

全10ステージのボリューム: ステージが進むごとに強大になるボスや部下たちを打ち破り、最終ステージのクリアを目指します。

インストール・起動方法

リポジトリをクローンまたはダウンロードします。

必要なライブラリ（Streamlit、Pillowなど）をインストールします。

Bash
pip install streamlit pillow
アプリを起動します。

Bash
streamlit run app_16.py
